SIN HUMO / SOLO DATOS

DATOS REALES. RUIDO CERO.

La TRM es el valor oficial en pesos colombianos por dólar estadounidense, calculado y certificado por la Superintendencia Financiera de Colombia. No es el precio de compra o venta en tiempo real de una casa de cambio.

Los registros se obtienen de Datos Abiertos Colombia ↗. La aplicación consulta la API en Python y renueva su caché cada 20 minutos. Los gráficos utilizan fechas de inicio de vigencia, sin rellenar artificialmente fines de semana o festivos.
